# 📊 Student Marks & Academic Performance Analysis using NumPy

A high-performance numerical data analysis project evaluating student examination scores, subject-wise trends, and grading distributions using Python and **NumPy**.

---

## 🎯 Objective
The primary objective of this project is to perform vectorized statistical analysis on student examination records. By leveraging **NumPy multi-dimensional arrays (`ndarrays`)**, the project eliminates slow iterative loops to compute student aggregates, subject difficulty metrics, grade distributions, and student rankings across multiple academic subjects.

Key goals:
* Compute individual student totals, percentages, and class-wide rankings.
* Evaluate subject-wise performance metrics (mean, median, standard deviation, pass percentages).
* Implement vectorized conditional masking to categorize students into performance tiers (Distinction, First Class, Pass, Fail).
* Identify students requiring academic intervention and support.

---

## 🛠️ Technologies Used
- **Programming Language:** Python 3.x
- **Core Numerical Computing Library:** NumPy (`ndarrays`, vectorization, broadcasting, boolean indexing)
- **Data Handling:** CSV / NumPy `.npy` arrays
- **Development Environment:** VS Code, Jupyter Notebook
